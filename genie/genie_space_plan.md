# Genie agent plan: ask the data in plain English

Phase 2 of the project. A **Databricks Genie space** turns questions like *"What was the 30-day readmission rate for Medicare patients last year?"* into SQL over the Gold layer.

## Why the Gold layer is ready for this

- **Star schema** with clear grain: `fact_encounter`, `fact_condition`, `fact_medication` around `dim_patient`, `dim_provider`, `dim_organization`, `dim_payer`, `dim_date`.
- **Primary and foreign keys** declared on every dimension and fact, so Genie picks the right joins.
- **Table and column comments** explain business meaning (for example `is_readmission_eligible` is the readmission denominator).
- **Pre-aggregated marts** give Genie fast, correct answers for the most common questions.

## Setup

1. **Genie agents > New**. Warehouse: Serverless Starter Warehouse.
2. Add tables: all `workspace.gold.dim_*`, `fact_*`, `agg_*` and `kpi_overview`.
3. **General instructions** (paste):

```
This is synthetic patient data for Massachusetts generated by Synthea (seed 42, 50,000 living patients).
"Today" for this data is gold.kpi_overview.snapshot_date, not the real current date. Use it for "last year", "last 12 months" and ages.
Costs are in USD. total_claim_cost = payer_coverage + patient_out_of_pocket.
Readmission rate = COUNT_IF(has_readmission_30d) / COUNT(*) over fact_encounter WHERE is_readmission_eligible.
Use encounter_class_label for display and encounter_class for filters.
Chronic disease questions use fact_condition.condition_group. Prevalence uses living patients (dim_patient.is_deceased = false) as the denominator.
Payer groups: dim_payer.payer_type (Medicare, Medicaid, Dual eligible, Commercial, Uninsured).
```

4. **Example SQL queries** (teach Genie the trusted patterns):

```sql
-- Readmission rate by payer type
SELECT py.payer_type,
       ROUND(COUNT_IF(f.has_readmission_30d) / COUNT(*), 4) AS readmission_rate_30d,
       COUNT(*) AS index_admissions
FROM workspace.gold.fact_encounter f
JOIN workspace.gold.dim_payer py USING (payer_id)
WHERE f.is_readmission_eligible
GROUP BY py.payer_type
ORDER BY readmission_rate_30d DESC;

-- Diabetes prevalence among living patients by age band
SELECT p.age_band,
       COUNT(DISTINCT c.patient_id) / COUNT(DISTINCT p.patient_id) AS prevalence
FROM workspace.gold.dim_patient p
LEFT JOIN workspace.gold.fact_condition c
  ON c.patient_id = p.patient_id AND c.condition_group = 'Diabetes'
WHERE NOT p.is_deceased
GROUP BY p.age_band
ORDER BY p.age_band;

-- Average cost per emergency visit by year
SELECT YEAR(encounter_date) AS year, ROUND(AVG(total_claim_cost), 2) AS avg_cost
FROM workspace.gold.fact_encounter
WHERE encounter_class = 'emergency'
GROUP BY ALL
ORDER BY year;
```

5. **Benchmark questions** to test before sharing:
   - How many living patients are there by gender?
   - Which 5 organizations had the most inpatient admissions in the last year?
   - What share of total cost did patients pay out of pocket, by payer type?
   - Which chronic condition is most common among patients aged 65-79?
   - What is the average length of stay for inpatient admissions, by year?
   - Top 10 medications by total cost last year.

## Later: agent outside Databricks

If the agent needs to live in a web app or chat tool, the Genie Conversation API exposes the same space programmatically. That keeps all SQL logic and permissions in Databricks.
